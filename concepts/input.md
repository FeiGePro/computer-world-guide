# 输入

## 一句话解释

输入是进入系统并参与处理的信息或信号。

## 本质压缩

输入不一定来自人，也可以来自文件、网络、摄像头、传感器或另一个程序。

## 别人通常会怎么说

- “输入文字”：通过键盘、语音或其他方式给程序提供文本。
- “输入设备”：向系统提供信号的设备，如键盘、鼠标、摄像头和传感器。
- “输入参数”：调用程序或函数时提供的条件和数据。

## 一个直觉类比

输入像进入加工流程的原料和指令。

## 类比的边界

某个系统的输出可以立刻成为另一个系统的输入，边界取决于我们正在观察哪一层。
